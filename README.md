# Microservicio CRUD con MongoDB

Microservicio RESTful desarrollado con Spring Boot y MongoDB para gestionar operaciones CRUD sobre una entidad del dominio.

Este repositorio formará parte de una práctica de laboratorio sobre:

- Arquitectura de microservicios.
- Base de datos NoSQL.
- Manejo de excepciones y validaciones.
- Pruebas unitarias e integración.
- Cobertura con JaCoCo.
- Análisis estático con SonarQube.
- Gitflow con GitHub.

Las instrucciones de instalación y ejecución se completarán en la documentación final.
